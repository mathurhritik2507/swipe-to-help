# Security Policy

## Current scope

This repository is a prototype and is **not** the authoritative synchronized source of the public deployment. Payments, securities investment transactions, and identity verification are not live features.

## Reporting vulnerabilities

Please do not disclose secrets, personal data, or exploit details in public issues. Contact the maintainer through the contact options on the [GitHub profile](https://github.com/mathurhritik2507) to coordinate a private report.

## Security expectations

- Never commit secrets or service-role keys.
- Enforce database row-level and server-side authorization for all user-owned records.
- Separate public profile data from private requests and evidence.
- Audit privileged moderation actions and prevent self-granted roles.
- Use provider-hosted payments and regulated partners before introducing financial transactions.

No security certification, third-party audit, or production-grade compliance is claimed.
